# ING & YVE Digital Gallery & Shop

## Goal
Build a complete, responsive luxury gallery and commerce experience for ING & YVE, with all requested pages, rich product imagery, refined editorial interactions, and a persistent three-concept theme switcher.

## Pages and shared experience
- Create a sticky concept bar plus responsive site header, navigation, search, account, and mini-cart controls shared across every page.
- Build `/` with a full-bleed editorial introduction, brand statement, three featured collections, bespoke teaser, craft story, and understated footer.
- Build `/collections` with category/material filters, an editorial product grid, and the KiKa charity collection banner.
- Build `/product/1` with an image gallery, sticky product details, material swatches, three configuration tabs, add-to-cart interaction, and craft/story accordions.
- Build `/bespoke` as a functional four-step configurator with shape and size choices, image upload preview and simulated verification, finish options, live pricing, and cart action.
- Build `/our-craft` as an image-led story of Dutch sourcing, circular production, leather trim, ceramics, and felt.
- Build `/about` with founder profiles and a consultation/contact form for private clients and professionals.

## Visual system
- Use Playfair Display for editorial headlines and Montserrat for interface/body text.
- Implement all three concepts as semantic theme tokens so the full interface changes instantly and consistently:
  - Dark Luxury: graphite, gold leaf, matte grey, warm taupe.
  - Light Natural: linen, greige, warm taupe, off-white.
  - Ode to Iris: ocean, sea blue, pearl/sand, gold details.
- Keep the experience spacious and architectural, with thin rules, restrained controls, large photography, and subtle reveal/hover motion.
- Generate a cohesive set of original gallery-quality images for lamps, materials, craft, and founders rather than using placeholders.

## Interaction details
- Persist the selected concept in the browser and apply it before the page becomes visible where possible.
- Make navigation usable on mobile through a compact menu.
- Make collection filters update the visible products immediately.
- Make product swatches, tabs, quantity/cart feedback, accordions, image selection, bespoke steps, upload preview, and live price calculation functional.
- Keep commerce demonstrative in-browser; no payment processing, account backend, or persistent server cart is included.

## Quality and discoverability
- Add distinct page titles, descriptions, social metadata, accessible labels, keyboard focus states, and meaningful image alt text.
- Check desktop and mobile layouts for overflow, overlap, image framing, and interaction clarity.
- Verify the final preview and resolve any build or runtime errors.
